# 练习模块 UI 模板

## 参考页面

以「单音极速反应」练习配置页和练习页作为视觉基准。这里统一的是页面框架、尺寸、间距、控件状态和练习生命周期入口；音域、输入方式、练习方式、同步默认值、判分、题目结构和结果指标仍由各模块产品决策决定。

实现或改造模块前，先阅读 `docs/product-decisions.md` 中该模块对应的决策和 `docs/specs/`。文案与交互按决策保留，视觉框架按本模板落地。产品决策与模板无法同时满足时，先列出冲突和影响，交由产品决策，不通过 CSS 或重构暗中改变行为。

## 配置页模板

### 页面层级

1. 使用学习模块共用的页面标题和「导读 / 练习 / 统计」页签，不在配置卡片里重复页面标题。
2. 练习方式或模块子模式按对应产品决策放置；需要放在配置卡片外时，使用与卡片相同的最大宽度并居中对齐。
3. 配置主体放入 `PracticeSetupFrame`，并使用 `.practice-free-config-content`、`.practice-free-section`、`.practice-free-section-heading` 等共用结构样式。
4. 先展示开始练习必需的核心设置，再展示长度、同步等常用项，低频或专业选项收进「更多设置」。具体字段顺序按模块依赖关系和已确认产品决策，不为了统一而删项或改默认值。
5. 配置摘要与开始操作使用 `.practice-free-action-dock`；为固定操作栏预留页面底部空间，并适配安全区。

### 视觉基准

- 配置卡片使用 `.practice-setup-framed-page`：最大宽度 `1120px`、居中、`16px` 圆角，内边距 `clamp(18px, 3vw, 34px)`，主题边框、表面色和阴影。
- 卡片以内容自然撑高，不为凑齐高度制造大块空白。组内成对设置保持视觉平衡，窄卡片通过容器查询折为单列。
- 标题、说明、分组标签、输入框、单选/复选项、分段按钮和主要按钮沿用现有公共样式与主题变量；不得在模块 CSS 中重写整张卡片的宽度、边框、背景、阴影、圆角或总内边距。
- 字段标题在控件上方；分组标题与控件间距使用公共样式。配置行之间采用紧凑、稳定的垂直间距，不按某一组内容长度撑开整页。
- 选中、禁用、错误和焦点状态使用主题变量及统一的可见焦点样式，浅色和深色主题都必须可读。
- MIDI / 麦克风等状态控件按产品决策放在配置卡片顶部或相应输入方式旁，不另造一套状态徽标和连接提醒。

### 响应式规则

- 使用卡片宽度而非只看窗口宽度决定两列折行；共用卡片在 `760px` 宽度内改为单列，音组选择在 `520px` 内改用小屏列数。
- `grid` 子项使用 `minmax(0, 1fr)` 并允许换行，长标签、说明和设备名称不得撑宽卡片。
- 手机页面允许纵向滚动；固定操作栏不得遮住最后一组设置。触屏按钮保持可操作尺寸，数字/文本输入按全站移动端聚焦滚动规则处理。
- 平板按实际可用卡片宽度布局，不把所有触屏设备一律当作窄手机。

### 共用组件

- 配置卡片：`PracticeSetupFrame`。
- 配置字段与选项：`PracticeSetupView`、`StaffDistancePracticeView` 使用的公共配置类，以及 MIDI 控件、音域组、分段选择和操作栏。
- 练习页：`PracticeSessionFrame` + `PracticeSessionHeader`；暂停统一使用 `PauseOverlay`，全屏统一使用 `PracticeFullscreenToggle`。
- 生命周期边界：配置、练习中、暂停、结算、退出/返回；失去输入设备、开始前校验和练习长度结束也要沿用模块的既有规则。

不要为每个 Level 复制一份近似的卡片、操作栏、练习头部或暂停蒙层。优先复用以上组件；确有语义或交互差异时，通过组合和小范围变体表达，并说明差异对应的产品决策。

## 练习页模板

- 练习外壳使用 `PracticeSessionFrame`，标题、进度和控制区使用 `PracticeSessionHeader`。
- 标题与进度关系遵循单音极速反应：题量进度紧邻标题显示；固定时长等附加状态在同一进度区展示。
- 结束返回、暂停、重新开始、输入设备和辅助操作进入公共头部对应区域；桌面与平板优先左右分区，窄手机按公共响应式规则换行。
- 练习主体置于头部下方并使用当前模块的标准内容宽度；谱面、钢琴、答案区、反馈区等保留模块语义和交互，不用标题栏或暂停蒙层表达业务反馈。
- 用户主动暂停统一用 `PauseOverlay`，只保留一个清晰的继续入口。谱面视野保护暂停时不显示暂停蒙层或暂停提示，保留冻结并允许用户滚动预览；当前音符重新进入视野后自动恢复。不得在蒙层外或蒙层底部重复放置不可达的继续按钮。
- 练习内容超出视口时由页面/内容区纵向滚动；固定键盘、节拍器和浮动控件遵循各自公共组件，不得遮挡答题内容。

## 模块配置与实现流程

1. 阅读产品决策与模块规格，列出必要配置、默认值、依赖、开始前校验、输入方式和结算数据。
2. 先画出字段层级：模式 → 核心范围/题目条件 → 输入与长度 → 更多设置；若模块决策要求不同顺序，保留决策并记录原因。
3. 选择现有组件和事件/状态边界；判分、出题、输入匹配、存档规则仍留在模块域逻辑中。
4. 按单音极速反应的框架实现配置与练习页面，不另建平行 UI 系统。
5. 对照窄手机、平板和桌面视口检查卡片宽度、折行、滚动、固定操作栏、深浅主题、暂停与结算状态。
6. 若旧产品策略确实要求与模板相反的布局或交互，不自行覆盖；把具体冲突、用户影响和建议选项提交产品决策。

## 模块边界

视觉一致不等于练习行为一致。模块可以保留自己的模式切换、音域、输入、节拍、题目生成、判分、反馈和统计；这些差异应由模块组件和纯逻辑表达，不复制公共页面壳，也不把不同数据模型合并。

和弦训练是首个对照模块：保留其调性、和弦组、转位、MIDI 与和弦级计分；配置卡片和运行页壳使用本模板与公共组件。练习方式位于配置卡片上方、MIDI 选择器位于卡片顶部，遵循和弦训练已确认决策。

和弦训练的呈现方式随产品决策更新：认和弦保留分步选择；柱式和弦与分解和弦弹奏使用连续谱面，一次显示多组和弦题并用光标标记当前组，不使用单题卡片。该差异属于练习主体，不改变公共练习页头部、暂停层和全屏控制。
