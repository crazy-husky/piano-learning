# 歌曲练习数据规则

## 新曲输入

- 新曲录入优先使用数字简谱；不建议把五线谱作为首选识别来源。没有简谱时仍可使用五线谱、MusicXML 或 MIDI。
- 用户直接提供 MIDI 时，以 MIDI 事件为曲目数据依据，不再从图片人工誊写旋律，也不自动移调、删音、合并重复音、重排段落或改写时值。
- 如果用户分别提供 C 调和原调 MIDI，将它们作为两个独立版本存储。配置页选择版本；演奏页可随时切换左手、右手或混弹。
- 手型筛选只决定当前练习展示和评分哪些声部，不修改来源 MIDI。混弹按来源时间点合并同时发声的音符。
- MIDI 音符的起点、时值、音高、声部、轨道、通道和来源事件序号均保留。需要分组以便展示或判定时，来源事件仍须完整保存。
- MIDI 的速度事件表也作为来源元数据保存；曲谱位置仍按 MIDI tick 换算成拍和小节。
- 曲谱 PDF 可与 MIDI 一起留档，记录来源和页数，供之后排查版本问题；PDF 不用于覆盖 MIDI 音符数据。

## 练习和统计

- C 调版与原调版使用各自的 MIDI 音高和速度。不得在运行时将其中一版计算成另一版。
- 歌曲练习沿用 MIDI 精确音高判定。歌曲练习统计单独保存，按曲目版本和演奏手型累计，不混入自由练习的音符熟练度或自适应数据。
- 歌曲模式不评节奏时，界面应明确说明按顺序弹奏即可；谱面时值和间距用于熟悉读谱。
- 歌词只有在用户明确要求录入时才加入。当前《匆匆那年》两个版本均不显示歌词。

## 审计边界

- 转换审计记录源文件 SHA-256、格式、轨道映射、速度、拍号、调号、每声部事件数、音域及 MIDI note-on/note-off 配对结果。
- 没有对应 note-on 的 note-off 事件不得当作音符；审计需记录其轨道、数量和样例，原始 MIDI 文件完整留档。
- 结构检查能发现转换或 MIDI 结构异常，但不能证明旋律与录音或谱图完全一致。音乐正确性仍需试听或对照来源确认。
- Audiveris、MusicXML 等识谱结果用于有谱图但没有 MIDI 时的录入，不与用户提供的 MIDI 互相覆盖。

## 当前曲目

- 《匆匆那年》保留用户提供的 C 调简单版与原调完整版 MIDI，配置默认 C 调版；旧原调 MIDI 不删除。两份对应的五线谱 PDF 作为来源材料留档，不再保留拆分的 PNG 页图。
- 当前接入保留两个 MIDI 的全部事件，并允许运行时切换左右手和混弹。音乐准确性尚未逐音人工核验。
- 《Always with Me / 千与千寻片尾曲》使用用户提供的 C 调简单版和 F 调原谱 MIDI，分别作为独立版本。对应的 2 页与 6 页 PDF 一并留档，不用旧的人工识谱数据覆盖 MIDI。
- 《Always with Me》原谱 MIDI 的右手轨道含 723 个完整音符，左手轨道含 628 个完整音符；另有 60 个没有对应起音的 note-off（右手 28 个、左手 32 个），只记入审计，不进入练习音符。所有原始 MIDI 均保存在来源目录。
- 《所念皆星河》已从歌曲练习目录移除。
