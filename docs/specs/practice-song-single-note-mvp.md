# `/practice` 歌曲单音练习

## 目标

在 `/practice` 配置页加入“自由练习”和“歌曲”两个标签。歌曲练习内置用户提供的《夜曲》四页数字谱转写结果，以整页五线谱展示 C 调单音声部，并将歌词放在高音旋律对应音符下方；支持单独练高音、单独练低音或混合顺序练习，弹完当前页后自动进入下一页。

## 交互

- 自由练习保留现有配置和流程。
- 歌曲页提供内置《夜曲》条目，不提供外部 MusicXML 导入。
- 内置谱面从用户提供的四页数字谱分别转写高音旋律与下排低音单音；排除柱式和弦，歌词对应高音旋律，小节位置保留。
- 可选择“只弹高音”“只弹低音”或“混合”。混合时按谱面位置合并成单音序列；同一位置高低音重合时保留高音并略去低音。
- 混合模式使用大谱表展示高低音，歌词位于高音谱表下方；同一时刻只显示一个练习目标音。
- 将 Ab 调数字谱按级数移到 C 调，只练 C 调自然音，并按原谱的上下点保留八度；歌曲模式不练和弦，也不做节奏判定。
- 用户选择虚拟键盘、MIDI 或麦克风，再点“确认并进入练习”。
- 练习页每页展示 24 个谱音，在音符下方显示对齐歌词，保留音符时值、八分/十六分音符连梁和小节分隔；正确音标绿，错误音标红且不前进。整页完成后自动翻页。
- 歌曲练习不写入自由练习的会话、复习或统计数据。

## 文件与结构

- `src/features/practice/song-practice/songPracticeMaterials.ts`: 声部合并、C 调白键转换和歌曲选择类型。
- `src/features/practice/song-practice/yeQuScore.ts`: 内置《夜曲》高低声部音符、节奏、小节和歌词转写。
- `src/features/practice/song-practice/SongPracticeView.tsx`: 歌曲练习状态、输入和分页。
- `src/features/practice/components/PracticeSetupView.tsx`: 两个练习标签、歌曲/声部选择和输入方式。
- `src/features/practice/components/StaffPagePrompt.tsx`: 复用五线谱布局，绘制歌曲单音、时值、小节线和对应歌词。
- `src/styles/song-practice.css`: 歌曲配置和练习页面样式。

## 输入规则

- 虚拟键盘只启用白键；混合模式不可选虚拟键盘。
- MIDI 按音名与八度匹配。
- 麦克风复用现有音高识别器，进入练习后由用户点击按钮授权并启动。

## 边界

- 内置转写只用于用户个人练习，不展示原始图片或柱式和弦。
- 高低音重合按原数字谱同一小节内的横向位置匹配；该位置来自图片转写的近似拍点。
- 不改变数据库、备份格式和普通练习数据路径。
