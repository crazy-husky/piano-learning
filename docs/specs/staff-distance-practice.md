# 音距速推：产品规格

状态：首版规格（2026-10-16）。

## 目标与定位

让已能定位单音的学习者，看到连续五线谱时迅速判断相邻音在谱上相隔几个位置，并把这种视觉反应带入实际弹奏。

提供三种训练方式：「看音距」练习判断音距步数；「弹音距」（原「弹奏下一个音」）练习根据当前音弹奏谱面上的下一个音；「单指专项」按卡片先弹参考音、再弹目标音。弹音距进入后先弹奏第一个谱面音作为起音，答对后开始逐音弹奏后续音；起音不计题或成绩。弹音距是读谱到琴键的迁移练习，只校验音高，不校验用户判断音距时采用的策略。

## 产品决定与入口

- 放在现有「练习」页面，不增加首页卡片或主导航菜单。
- 练习设置页顶部页签为「自由练习 / 音距速推 / 歌曲」。页签写入练习路由的 `tab` 查询参数；音距速推下方再提供「看音距 / 弹音距 / 单指专项」三个页签，写入 `distanceMode`，刷新和浏览器返回后恢复。切换子页签时，下方只显示当前训练方式对应的设置。
- 音距速推的练习长度、最大步数、0 步开关、谱面时值、训练方式和弹奏输入方式保存为独立本地偏好；再次进入时沿用上次配置。
- 练习运行中按应用返回键或浏览器返回，先结束并保存本局，再回到当前页签的配置页；完成总结页按应用返回键或浏览器返回，则收起总结并回到该配置页。配置页的应用返回键仍返回首页。
- 「看音距」页签用数字按钮或实体键盘作答；「弹音距」页签先正确弹奏第一个音作为不计题的起音，再使用 MIDI、麦克风或符合音域条件的物理键盘逐音作答，均按实际音高和八度判定。弹音距不提供仿真钢琴键盘。不校验用户判断音距时采用的策略。未连接 MIDI 时开始按钮保持可点击，点击后提示连接 MIDI 或切换麦克风。
- 页面标题为「音距速推」，说明文案：「看清当前音与下一个音的距离，练习快速判断并找到下一个琴键。」看模式题干：「当前音和下一个音相隔几步？」弹奏模式题干：「根据当前音，弹奏谱面上的下一个音。」
- 完成页提供「练习单音弹奏」按钮，回到自由练习并切换为单音显示，让用户用原有弹奏流程练习迁移。

## 数字的定义

从当前音符中心到相邻的上一线/间或下一线/间算 **1 步**；起点不算，方向不计入答案。跨越八度时继续按自然音级逐级计数，不按半音数、白键数或两音之间夹着几个音符计数。

| 示例         | 正确输入 | 说明                             |
| ------------ | -------: | -------------------------------- |
| C4 → D4      |        1 | 相邻谱位                         |
| C4 → E4      |        2 | 乐理上是三度；这里只输入 2       |
| F4 → C5      |        4 | 乐理上是五度；这里只输入 4       |
| C4 → 上方 C5 |        7 | 跨一个八度；仍按谱位逐级计数     |
| E4 → C4      |        2 | 下行也输入 2                     |
| G4 → G4      |        0 | 同一谱位连续再弹，按原地重复处理 |

教学和反馈统一使用「上/下移动 N 步」；乐理音程名称只在帮助说明里作为可选补充。避免使用「隔几个音」「跨几格」这类容易产生不同计数方式的题干。五指位置下，C→E 可以是 1 指到 3 指，但实际指法取决于手位、起始手指及后续乐句，因此不显示固定手指答案。

## 设置页

「音距速推」配置页提供以下控制：

- **训练方式和输入**：配置区以「看音距 / 弹音距 / 单指专项」三个页签切换内容。「看音距」显示音距步数设置；「弹音距」显示音距步数和 MIDI/麦克风选择，音域符合条件时在所有设备上额外显示物理键盘；非电脑设备选择物理键盘时提示必须连接外接实体键盘。「单指专项」显示手别、手指和 MIDI/麦克风/仿真钢琴键盘选择。所选页签与输入方式分别记住；实体弹奏输入按谱面实际音高和八度判定，单指专项可选独立仿真键盘。

### 弹音距的物理键盘输入

- 仅「弹音距」提供物理键盘输入；看音距和单指专项不受影响。所有设备均显示此选项；实际练习音域在低音侧最多覆盖一个音组、高音侧最多覆盖一个音组时可选，跨组加练音也参与检查。非电脑设备选中后弹窗提示需要外接实体键盘。低音组由左手键位负责，高音组由右手键位负责；没有低音音组时隐藏左手键位，没有高音音组时隐藏右手键位。
- 左手 C–B 默认映射为 ·123456，右手 C–B 默认映射为 ghjkl;'。键位使用物理 KeyboardEvent.code 识别；用户可逐个重新设置，也可恢复默认。禁止同一个按键对应多个音，避免双手音域同时启用时产生歧义；空格、回车、Esc 等页面操作键不可分配。
- 映射和物理键盘输入方式保存为本地偏好；开始时把本局映射写入练习快照。每次按键都转换为对应的音名、八度和 MIDI 音高，首个起音及之后的目标音都按精确音高判定，记录为物理键盘输入。
- 音域变为不适用时，隐藏该输入方式并自动切回用户上次选择的 MIDI/麦克风，同时提示切换原因；键位偏好保留。

1. **音域和谱号**：自由练习和音距速推共用同一份当前音域，谱表模式分别记住最近一次的音域选择，切换模式后可以继续微调。高音谱表主体音域从 C4（中央 C）开始，低音谱表主体音域最高到 B3。所有模式都可在当前音域两端分别加练 3 音或 5 音，仅受钢琴可用音域边界限制；向低和向高可同时加练，同一方向选一个跨度，改选时替换该侧范围。点击已高亮选项可取消对应一侧，“取消加练”按钮清除所有加练。高音谱表中低于 C4 的加练音、低音谱表中高于 B3 的加练音作为跨手识谱，并仍记在当前谱号；相应说明用红色突出。大谱表加练只扩展总音域，并按固定分界归谱：C4 及以上记在高音谱，B3 及以下记在低音谱，不做单谱模式那样的跨手交叉练习。自由练习从大谱表所选的两行音域共同出题，不按上一题所在谱表锁定整页；音距题只从同一谱表的音对中生成，不从一只手的音区跳到另一只手。音距速推练习不重复生成同一音高的另一谱表写法。所选范围须能为每个启用的距离生成至少一对同谱表音；否则说明缺少哪些距离及原因，并禁止开始。
2. **最大音距**：1 至 7 步，默认上限 2 步。看模式的数字键提供 `1` 到当前上限；启用同音练习时额外提供 `0`。距离为 0 时两个音落在同一谱位，表示同音连续再弹，可单独关闭。0 步只占少量题目，不与各非零距离等频抽取。上限为 1 且关闭 0 步时，因只剩一种答案而禁止开始。
3. **七步跨度规则**：上限设为 7 步时，所选音域至少覆盖两个连续音组。音组按全局音域选择器中的大小字组划分；必须从实际选中的音高推导音组，不能依赖已被音域选择器清空的旧组 ID。连续两组只是必要条件，还必须在同一谱表内有一对相隔 7 步的音；大谱表中跨 C4/B3 分界、分别落在两行谱表的音不能组成这道题。例如高音谱需要包含 C4 和 C5，低音谱需要包含 C2 和 C3。无法生成时，明确解释是“组虽连续但分属两行”或当前音域缺少同谱表的 7 步音对，并给出补充同谱表音域、使用加练或缩小最大音距的建议。
4. **谱面时值**：增加全音符、四分音符、八分音符、十六分音符选项，支持多选，默认只选四分音符并保存在音距速推练习偏好中。所选时值是节奏生成器可用的音符值；按 4/4 小节生成有效节奏，并在谱面标出 4/4 拍号，而不是逐音等概率抽取。四分音符可单独出现，八分音符按拍成对，十六分音符按拍分组并可混合八分音符；不生成休止符或空拍。全音符占满一小节，低频出现。每页谱面使用可用横向空间；根据实际节奏间隔及最小可读音符间距，计算本页能容纳的音符数。放不下下一个音符时换页，并在新页重复上一页末音，保证页边界题目连续。音符不因一页题数固定而挤在一小段谱面，也不把少量音符拉到过大的谱面里。时值影响谱面节奏、连梁和音符间距，但不改变练习计时、题数、答案或节奏播放。
5. **练习长度**：沿用无限、固定题数、固定时长。这里的「1 题」是一对相邻音的距离；首个起点音不计题数。定时结束时，正在显示但尚未输入的题不计为错误。
6. **显示**：固定为连续五线谱，不显示现有的单音/谱页切换、训练策略、音名/MIDI/麦克风答题方式及自动播放目标音等无关选项。现有自由练习设置保持原值。

首版只使用自然音、最多 7 步和单音事件；低音谱可以把自然音三和弦拆成连续单音音型，不同时叠放多个和弦音。暂不出升降号或八度标记。大谱表模式按 C4/B3 边界将音符记在对应谱表；自由练习的连续谱页和旋律生成从所选高、低音域共同出题；看音距的每一对音仍保持在同一谱表。单谱模式只使用所选谱号。用户选择的 3 音或 5 音边界加练范围低权重穿插，不与主体音域等权抽取；大谱表也允许加练，新增音同样按 C4/B3 规则归谱，不产生跨手交叉练习。

大谱表音距速推练习交替生成高音谱和低音谱的短音段，每段最多包含 6 个计分音对。谱表交接处的那一对音不计题，交接处用小节线分隔，不留空拍或显示休止符。每道实际计分题仍由同一谱表的相邻两个音组成，不出现跨手区的距离题。桌面宽谱页通常能显示两行谱表的音符；窄屏按实际可容纳的音符数分页，单页可以只显示其中一段。未承载音符的另一谱表用不可见占位保持节拍。

## 练习画面与交互

```text
音距速推 · 看音距              第 3 / 20 题     暂停

五线谱：   ♪  ♪  ♪  ♪  ♪  ♪  ♪  ♪
                    └当前─下一个┘

当前音和下一个音相隔几步？
          [ 0 ] [ 1 ] [ 2 ] [ 3 ]
          [ 4 ] [ 5 ] [ 6 ] [ 7 ]
```

弹奏模式沿用同一谱面和题目进度，题干改为「根据当前音，弹奏谱面上的下一个音」，下方显示 MIDI、麦克风或物理键盘提示，不显示数字按钮。

- 一次显示一页连续音符。看模式中首个音是起点，第 1 题比较第 1、2 个音。弹奏模式先要求弹对第 1 个音，该起音只作为开始位置，不计题或成绩；随后才弹奏第 2 个及后续音。答对后后一音成为新起点。大谱表每 6 个计分音对左右切换一次谱表，交接处的一对音不计题，页面仍展示交接前后的音段。每页根据实际可用宽度和节奏间隔计算音符数；放不下下一个音符时切到下一页，并保留上一页末音作为新页起点，避免跳过页边界的距离。
- 看模式答对一组距离后，将该组起点音标绿（如 A–B 答对标绿 A，B–C 答对标绿 B）；弹奏模式答对后将目标音标绿，正确弹奏第一个起音后也标绿。未答对的音保持默认颜色。粉色定位条标记当前音，其他音仍可提前看见。答对后在页内移动标记；到本页末题时换页。手机也按实际可读宽度计算每页音符数。
- 看模式谱下显示大数字按钮，范围为 0 到所选最大音距；关闭同音时不显示 0。3 个及以下按钮显示一排；4 个时排成 2+2；超过 4 个时尽可能均分到两排、每排不超过 4 个（5 个时为 3+2，7 个时为 4+3）；按钮组收窄并居中，两排分别居中，减少点击时的横向移动。答案按钮下方以紧凑区域块显示左对齐的举例和线间奇偶规律。电脑数字行和数字小键盘接受相同数字。按钮有文本数字、焦点状态和足够触控面积。
- 看模式答对后短暂显示「2 步」并自动前进；弹奏模式弹对下一个音后前进。答错时保留当前音对并允许重答；看模式连续两次答错或点「提示」后，可显示逐个谱位的辅助标记。提示后仍需完成当前模式的作答才能继续。首次输入决定本题的正确率与反应时间，重答不抹去首次错误。
- 设置页常驻显示简短例子：「C→E 输入 2」「下行也只输入音距步数」「同音输入 0」。固定题数仍按可用宽度分页，题号用于显示进度，不单独显示页码。正式练习提供暂停、继续和结束；结束后进入本局总结，可从总结页再练一局回到配置，不提供单独的返回按钮。电脑端空格暂停/继续，Esc 结束；暂停时不计反应时间。触屏设备不显示数字键、空格或 Esc 快捷键说明。
- 不显示音名标签或琴键提示，防止用户改为逐音认读。

## 出题音型

- 不再均衡轮流抽取每个可用距离。高音谱的非同音音距基础概率为：1 步 30%、2 步 30%、3 步 20%、4 步 10%，5–7 步各约 3.3%；上行和下行按近期数量平衡。大谱表每段最多连续练 6 个音对后切换谱表，切换时跳过边界音对，但不改变其他音对的音距分布。启用 0 步时同音另占约 5%，其余非同音音距按比例缩放。实际出题比例会受当前音域可用音对、方向平衡和每 20 题段远跳覆盖规则影响。
- 低音谱优先抽取自然音范围内的常见大、小三和弦分解音型，如根音—三音—五音—高八度根音，或根音—五音—高八度根音。约 45% 的低音转换可来自完整和弦短句；其余题目偏向中、大跨度移动。大小三和弦以当前音域内实际可用的音为准，单个相邻移动仍不得超过用户设定的最大步数。
- 两个方向都要出现较大跳进。最大音距和所选音域允许 5–7 步跳进时，每个完整 20 题段至少包含一次高到低和一次低到高的远跳；超出最大距离或不在所选音域的音型不得生成。
- 和弦首版以分解形式呈现，保证每题都是「当前音到下一个音」的一组单音音距答案。暂不加入同时发声的柱式和弦。

## 结果与数据边界

- 完成页显示题数、首次正确率、首次答对题的反应时间中位数，以及 0 至最大步数各自的表现；用户无需输入方向。设置页回看最近五局。
- 音距速推练习使用独立记录，不写入现有单音熟练度、单音错题、闯关进度或默写成绩。首版只展示本局总结和最近五局，不并入现有单音统计趋势。
- 作答事件的每次 attempt 保存实际输入；看模式额外记录用户选择的步数，即使该次答错后重答正确，也能回溯误选项。
- 反应时间从当前两音成为焦点开始，到首次数字输入或目标音输入为止；弹奏模式的起音不计入任何题目反应时间。暂停及页面失焦时间不计入。首次错误、提示使用和未完成题保留各自状态，避免把重答时间当成首次识别速度。
- 看模式完成后可以进入现有自由练习；弹奏模式先以第一个音起步，再逐音练习 MIDI、麦克风或符合条件的物理键盘输入。弹奏模式展示目标音，因此作为看谱到琴键的迁移练习，不把成绩解释为用户一定采用了数谱位策略。

## 验收条件

1. 看模式中 C→E、E→C 均只接受数字 2；F→上方 C 只接受 4；C4→上方 C5 只接受 7；同一谱位重复只接受 0，题干为「当前音和下一个音相隔几步？」。弹奏模式先要求弹奏第一个音；正确后才开放后续音，起音不计题、不计成绩，答错时标红并可重试；其后正确弹奏目标音后前进，音名相同但八度错误仍判错。
2. 答对一题后，后一音成为下一题起点；跨页时不存在漏题或重复计题。
3. 谱面上始终可以辨认当前两音；看模式答对后，作为当前组起点的音符标绿；弹奏模式答对后，作为目标音的音符标绿。未答对的音保持默认颜色。看模式显示数字选项且可用实体键盘数字键；弹奏模式提供 MIDI、麦克风及符合条件时的物理键盘输入，不显示仿真钢琴键盘。
4. 答错和使用提示不会推进题目，也不会把该题改算首次答对。
5. 音距速推练习结束后，现有自由练习的设置和历史不被覆盖；音距成绩独立可回看。音距速推设置、训练方式和弹奏输入方式在再次进入后保留。
6. 最大音距为 7 时，所选音域没有覆盖两个连续音组不可开始；覆盖两个连续音组后，还必须实际存在同一谱表内相隔 7 步的音对。设置和开始前校验都使用实际音高选择；大谱表无法生成时提示用户在中央 C 右侧的高音区或左侧的低音区选择连续多组音符，不将旧组 ID 误判成未选音组。
7. 高音谱的 1–2 步题占多数；低音谱能够出现自然音三和弦分解音型；最大音距和音域允许远跳时，每个完整 20 题段都包含向上和向下的 5–7 步跳进。
8. 全音符、四分、八分和十六分时值支持多选，设置离开页面后保留，旧的单选设置继续兼容；按 4/4 拍组合节奏并显示拍号，八分/十六分连梁遵循拍内分组，不生成休止符或空拍，也不在大谱表的空声部显示填充休止符。谱面占用当前可用宽度，按节奏间隔和最小可读间距动态计算每页音符数；空间不足时换页并重复上一页末音，音符不拥挤且页边题目不丢失。小节线仅表示 4/4 小节或高低音谱表交接，不在谱尾添加终止线。题数及计时规则不随时值改变。触屏设备不展示无用的键盘快捷键说明。

9. 高音谱表主体音域不低于 C4，低音谱表主体音域不高于 B3；所有模式都能在音域上下两端加练 3 音或 5 音，受钢琴可用范围限制，两侧可同时启用，同一侧只保留一个跨度。高音谱表低于 C4、低音谱表高于 B3 的加练音作为跨手识谱并保留当前谱号，说明标红；大谱表仍按 C4/B3 分界归谱，不做单谱模式的跨手交叉。点击当前高亮选项可取消对应一侧，“取消加练”清除所有加练；高音谱、低音谱和大谱表的范围配置分别保留，自由练习和看音距读取相同配置。大谱表下 C4 及以上出现在高音谱，B3 及以下出现在低音谱；如果所选音域覆盖两边，自由练习的谱页和旋律都能生成两边的音符；音距速推在桌面宽谱页交替展示两行音符，但交接音对不计题，实际计分音对保持在同一谱表。

## 实现边界与验证建议

- 大谱表验收：C4 及以上必须画在高音谱，B3 及以下必须画在低音谱；所选音域覆盖两边时，自由练习谱页能出现两边音符，音距速推的桌面宽谱页能出现两边音符，窄屏可只显示当前段；高低音段交接音对跳过且不计题，所有计分音对保持在同一谱表；大谱表可以设置向低或向高加练，新增音仍按 C4/B3 分界归谱，不产生跨手交叉。
- React/TypeScript 界面沿用练习页面与现有 VexFlow 谱面绘制能力；看模式显示数字输入组件，弹奏模式复用 MIDI 和麦克风音高输入管线，均不能混用自由练习的配置状态。
- 弹奏模式的物理键盘映射依据本局设置快照，以物理键位解析出自然音和八度并复用精确音高判定；该选项在每侧最多一个实际音组时出现，非电脑设备需提示用户连接外接实体键盘。
- 音距计算做成独立纯逻辑：以自然音级和八度计算绝对距离，限制最大跨度，并保证输入音都来自所选音域和同一谱表。
- 数据结构需要明确标记练习类型，独立保存音距题记录；备份、导入和统计须识别该类型，避免旧单音统计误读。
- 实现时针对跨 C 边界、上下行、同音、稀疏音域、页边界、首次错误与暂停计时做有意义的逻辑验证。项目现有本地命令为 `pnpm test` 和 `pnpm exec tsc -b --pretty false`；生产构建按仓库开发说明执行。

## 待验证的产品假设

- 先只答音距步数，可以提升看谱判断音距的速度；完成页需要引导进入弹奏练习，观察迁移是否成立。
- 默认最大 2 步、同音开启，既能快速上手，也能避免一开始出现过多大跳。可根据实际完成率和反应时间再调整默认值。

## 单指专项

单指专项是音距速推中的第三种训练方式，与看音距和弹奏下一个音共用练习入口及 MIDI/麦克风管线，但使用独立卡片和记录。配置按「练习方式 → 左右手及手指 → 输入方式」顺序展示。普通作答可选 MIDI、麦克风或单指专项专用仿真钢琴键盘；免答模式无需选择输入设备。音域由手别固定，不提供用户选择：左手使用 C2–B2、C3–B3 两组，右手使用 C4–B4、C5–B5 两组。右手使用高音谱，左手使用低音谱；普通音域、音距和练习长度设置不参与此模式。

| ---- | ---: | ---------: | ---------: | -------------- | -------------- |
| 右手 |    1 |          2 |          5 | E4             | F4             |
| 右手 |    2 |          3 |          4 | G4             | A4             |
| 右手 |    3 |          4 |          3 | B4             | C5             |
| 右手 |    4 |          5 |          2 | D5             | E5             |
| 右手 |    5 |          6 |          1 | F5             | G5             |
| 左手 |    1 |          5 |          2 | F3             | G3             |
| 左手 |    2 |          4 |          3 | D3             | E3             |

每个批次中，参考音以下和以上共 7 个目标音；每个目标音出现两次，随机排列，连续卡片不使用同一个目标音。整轮先完成 14 张线上参考音卡片，再完成 14 张间上参考音卡片。每张卡片同时显示参考音和目标音，参考音上方标明所选手指；演奏顺序固定为参考音、目标音。两个音都必须弹奏正确才算完成卡片。

卡片显示时开始 5 秒倒计时，两个步骤共用此倒计时。错误时留在当前步骤重试，计时继续；暂停冻结倒计时；超时后将未完成步骤记为超时并自动显示下一张卡片。参考音和目标音分别记录首次弹奏是否正确、错按次数及该卡是否超时。MIDI、麦克风和单指专项专用仿真钢琴键盘均按精确音高判定。

#### 免答模式

配置页提供「弹奏作答 / 免答模式」选择；运行页不提供模式切换按钮，要切换时先结束当前练习并返回配置页。首次开始免答模式时先弹出玩法提示；用户确认后从本轮第一张卡开始，并清理刚结束的普通作答轮次，避免两种模式的答题记录混合。之后在配置页切换到另一模式时也从第一张卡重新开始，并确认将重开本轮。免答模式沿用 28 张卡片和线上、间上批次顺序，但不检测 MIDI、麦克风或钢琴键盘输入，不启动卡片倒计时，也不自动切卡。谱面下方显示只用于查看音高相对位置的只读钢琴键位图，完全不接收点击、按压或作答输入；九个白键等宽铺开，键床宽度最多为标准键宽乘以用户校准比例后的真实宽度；视口更窄时按比例缩小至可用屏幕宽度。免答仍不受键盘宽度门槛和屏幕方向限制。操作区显示「查看答案」与「下一个」。目标键初始不高亮；点击「查看答案」后，用暖金色高亮目标白键并显示建议手指，区别于标记参考音及所选手指的绿色键；点击「下一个」后切换卡片并清除答案高亮。未查看答案也允许手动进入下一张。免答模式不写入答题事件、正确率、错按次数或超时结果；浏览完整轮后显示完成状态，可重新浏览或返回配置。运行页在「重新开始」右侧提供「操作说明」，只介绍当前模式：弹奏作答说明参考音、目标音、答错重试与 5 秒限时；免答说明只展示免答流程。

单指专项可选择专用仿真钢琴键盘；原有共享虚拟键盘维持现状，其他练习不受影响。键床固定为 9 个白键，覆盖线上、间上两批各自 8 键活动范围的并集，两批显示相同的绝对音高范围；白键标称宽度约 23.6 mm，可使用 85.6 mm 标准银行卡或身份证长边校准实际屏幕尺寸，校准比例保存在本地浏览器设置中；夜间模式下白键改用较暗的中性灰，目标键保持低亮度的绿色高亮；黑键依实际音高以长方形绘出，高度随白键高度从正常黑键高度的 50% 逐步增加至 100%；键面不显示音名或音组编号。当前卡参考音对应的白键显示并高亮当前手指编号，作为指法锚点；键床起点按手别、手指及线上批次活动范围计算，不随本题目标音或批次改变。右手线上参考键从左起固定为第 3–7 键，左手为第 6–2 键；进入间上批次后，参考音标记在同一键床上向右移动一个白键。当前题目仅使用自然音，因此黑键不接收输入。触屏按下白键时，按准确 MIDI 音高和八度即时判分，不依赖触屏压力值。参考音按对后可继续按住，也可先抬起，再用新触点按目标音；答错时保留当前步骤供重试；使用仿真钢琴键盘时，错误文字在固定高度的操作指导位置显示，约 1 秒后恢复当前步骤指导，不推动键盘布局。答对或超时后，等键盘上的全部触点抬起再进入下一卡。键盘区域禁止浏览器缩放、页面手势、文字选择和长按菜单；鼠标与键盘输入照常工作。

当前方向或旋转后的方向至少能容纳最小校准尺寸的完整键床时，显示可弹奏仿真键盘选项，以便窄屏用户选择该方式后调小尺寸；键盘宽度不足时点击开始会展开尺寸校准并用引导箭头指向尺寸滑块。免答模式不执行任何尺寸门槛。练习进入运行阶段后隐藏左侧主导航。可弹奏键盘运行页按整个视口宽度判断，不受页面内容容器左右边距限制；琴键仍按校准后的真实宽度绘制，不随屏幕拉伸，也不通过压缩标准键宽或横向滚动条适配。若当前方向宽度不足，提示应区分已在横向但键盘尺寸仍过大的情况和旋转后可容纳的情况，并暂停本卡倒计时，恢复可用宽度后自动继续。免答键盘是只读位置示意图，九个白键等宽铺开，宽度最多为按用户校准比例计算的真实键床宽度；视口更窄时缩小至可用屏幕宽度，不受方向或键宽门槛限制。所有输入模式下，单指专项都收紧谱表顶部留白；仿真键盘模式进一步放大五线谱并缩小周边留白。“5指”和“目标”标签在所有输入方式下均固定于对应谱表顶线以上 50 px，避开所有音符符头；所有输入方式均在当前待弹音上方 20 px 处显示红色三角标记，并随参考音与目标音切换。可弹奏键盘从题目提示区域下方开始使用剩余可视高度，布局和滚动变化后重新测量，最大约 150 mm；免答只读键盘限制为适中高度，不随剩余屏高扩展；参考手指和目标指法标签位于黑键下沿以下的白键区域，避免被遮挡。页面允许纵向滚动，短屏时保持至少可操作的琴键高度。答错时屏幕周边使用低对比度的柔和红色径向渐变提示，不显示实线边框；每次答错都会重新触发，约 1.5 秒后淡出。键宽初始按 CSS 标称物理单位绘制，可用 85.6 mm 参考卡进行设备屏幕校准；浏览器缩放或设备显示缩放改变后需要重新校准。

## 单指专项验收条件

1. 右手使用高音谱、左手使用低音谱；线上批次参考音按表中音高显示，间上批次参考音是紧邻的更高自然音谱位。
2. 卡片中显示两个音，参考音上方显示所选手指编号。必须先弹对参考音才接受目标音；目标音正确后立刻进入下一张卡片。
3. 每个批次包含 14 张卡片，目标范围内 7 个音各出现两次；顺序随机，当前卡与下一卡的目标音不连续重复，包含两个批次交界处。
4. 普通作答模式的单卡总倒计时为 5 秒，错误不重置时间，暂停时冻结；超时自动前进并保留参考音、目标音完成状态及超时数据。免答模式不显示倒计时，只能通过「下一个」换卡，不产生超时结果。
5. MIDI、麦克风和单指专项专用仿真钢琴键盘均精确匹配音高与八度；仿真键床固定 9 个白键，两批显示相同的绝对音高范围，不显示音名或音组编号。线上批次的参考音键按手别和手指固定位置；间上批次参考音在同一键床上向右移动一个白键，且批次内位置不随目标音变化。普通弹音距及其他练习继续使用各自原有的输入方式和虚拟键盘组件。
6. 可弹奏键床宽度不足时不显示溢出的键床；根据当前方向和键盘尺寸提示旋转设备或返回设置调小尺寸，并冻结本卡倒计时；练习运行时隐藏左侧主导航，调整到可用宽度后自动恢复。免答模式不检查键宽，显示只读键位图供查看相对位置，不接收点击、按压或作答输入。可弹奏键盘在首次进入、布局变化和滚动后重新计算可用高度，使用题目区下方剩余可视高度，最高约 150 mm；免答只读键盘保持适中高度，不随剩余屏高扩展；允许纵向滚动，不出现横向滚动条。仿真键盘输入时，五线谱较 MIDI/麦克风输入布局放大，且周边空白更紧凑，不裁切谱号、拍号、手指标记和目标音；五指与目标标签基线固定，并与所有音符符头保持间距；所有输入模式均在当前待弹音上方 20 px 处显示红色三角标记，并随参考音与目标音切换。
7. 完成页分别汇总参考音与目标音的首次弹对率、超时卡片数，并按线上、间上批次区分表现。
8. 在配置页选择「免答模式」后首次开始时先说明玩法，确认后开始一轮新的免答练习。免答模式显示「查看答案」与「下一个」；查看答案后仅高亮键盘目标白键，手动下一张后取消高亮。免答练习不能触键作答或自动切卡，不生成作答成绩；完整浏览后可重新浏览或返回配置。操作说明弹窗只介绍当前选择的模式；弹奏作答说明参考音、目标音、答错重试及 5 秒限时。运行页没有免答模式按钮。
